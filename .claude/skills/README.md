de <https://github.com/DietrichGebert/ponytail> (licença MIT, ver `ponytail/LICENSE`), commit `96608e0`
de 2026-10-29. Só os arquivos `SKILL.md` foram trazidos; os hooks e o plugin não.

Para atualizar: copie de novo os `SKILL.md` da versão nova e registre no `docs/CHANGELOG.md`.
O uso é obrigatório neste projeto (ver `CLAUDE.md`).
