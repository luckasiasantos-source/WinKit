# Validação do M12 — Aplicar neste PC e ponto de restauração

**Versão testada:**   **Data:**

Hipóteses a confirmar: **H13**, **H14**, **H15**.

## Ponto de restauração "Windows pronto" (instalação)

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Instalar a VM com o pendrive (ponto de restauração ligado, 5%) | No fim da Fase 2, "Criar um ponto de restauração" → "Restauração do Sistema" mostra "WinKit — Windows pronto (data)" | | |
| 2 | Proteção do `C:` | Ativada, com espaço máximo ≈ 5% | | |
| 3 | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\SystemRestore` | Sem o valor `SystemRestorePointCreationFrequency` (ou com o valor de antes) | | |

## Aplicar neste PC (Windows já instalado)

Preparação: uma VM com Windows 11 já instalado e "sujo" (apps de fábrica, sem ajustes). Crie antes um arquivo `%APPDATA%\discord\settings.json` com um texto seu.

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 4 | Studio → "Aplicar neste PC" | Lista "O que aplicar" com as categorias da receita; botão "Aplicar" desabilitado | | |
| 5 | "Ver prévia" | Cada item mostra "vai mudar" / "já está assim"; backups dizem quantos arquivos serão copiados e quantos mantidos | | |
| 6 | Desmarcar uma categoria | O botão "Aplicar" desabilita até refazer a prévia | | |
| 7 | Desligar "Criar ponto de restauração antes" | Pede confirmação | | |
| 8 | "Criar ponto de restauração e aplicar" | Ponto "WinKit — antes de aplicar" criado primeiro; apps instalados; ajustes e bloatware aplicados; resumo abre | | |
| 9 | `%APPDATA%\discord\settings.json` | Continua com o **seu** texto (merge, R-21) | | |
| 10 | Aplicar de novo (prévia) | Quase tudo "já está assim" | | |
| 11 | Restaurar o ponto "antes de aplicar" | O Windows volta ao estado anterior | | |
| 12 | `winkit aplicar --pendrive E: --simular` e `E:\WinKit\Agent\winkit-agent\winkit-agent.exe apply --root E:\ --simular` | Mesma prévia, sem mudar nada | | |
| 13 | `C:\ProgramData\WinKit\Aplicacoes\<data>\` e `WinKit\Logs\<pc>_<data>_aplicar\` no pendrive | Estado, resumo e logs da aplicação | | |
