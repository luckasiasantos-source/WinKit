# Validação do M16 — Contas, pastas e jogos

**Versão testada:**   **Data:**   **VM:** dois discos virtuais (disco 1 = Windows, disco 2 = dados)

Hipóteses a confirmar: **H32**, **H33** e a H11 (grupo pelo SID) para as contas extras. Nunca use discos reais de outra máquina; o WinKit acha volumes pelo número de série e nunca troca letras.

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | No Windows antigo, Documentos e Downloads em `D:\Usuarios\<você>\…` | — | | |

| 3 | Marcar Imagens também e "Copiar agora" | Os arquivos do C: aparecem no D:; nada é apagado nem substituído | | |
