# Validação do M6 — Backups de configuração

**Versão testada:**   **Data:**

## Preparação (no seu PC, como administrador)

Escolha 2 ou 3 apps que você usa e que têm configuração própria (ex.: Discord, VS Code, Notepad++).

```powershell
.\winkit\winkit.exe coletar backups --pendrive V:                      # mostra sugestões
.\winkit\winkit.exe coletar backups --pendrive V: --adicionar-recomendados
.\winkit\winkit.exe backup adicionar "C:\Users\<você>\Documents\Minha Pasta" --pendrive V:
.\winkit\winkit.exe backup capturar --pendrive V:                      # com o Discord ABERTO
.\winkit\winkit.exe backup listar --pendrive V:
.\winkit\winkit.exe construir --pendrive V:
```

## Passos

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | `coletar backups` | Sugestões dos apps marcados; aviso de token no "Local Storage" do Discord | | |

| 3 | `vssadmin list shadows` depois da captura | Nenhuma cópia de sombra sobrando | | |
| 4 | `V:\WinKit\Perfis\padrao\Backups\<id>\dados` | Arquivos legíveis; sem pastas Cache/GPUCache | | |
| 5 | Editar um arquivo em `dados\` à mão | — | | |
| 6 | Instalar a VM | — | | |
| 7 | Abrir o app pela primeira vez | Configurações do PC antigo já aplicadas (tema, preferências) | | |
| 8 | Conferir o arquivo editado no passo 5 | Versão editada à mão (D-005) | | |
| 9 | `C:\Users\Default\AppData\Roaming\<app>` na VM | Contém o backup (restaurado antes do login — H4) | | |
