# Validação do M20 — Modo em etapas, caminho, Ventoy e Rufus

**Versão testada:**   **Data:**   **PC/VM:**

Hipóteses a confirmar: **H39** (opções do Rufus legíveis), **H46** (Ventoy e Rufus abrem pelo WinKit).

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Abrir o Studio sem pendrive | A primeira etapa é **Começar**; a barra de baixo mostra "Etapa 1 de N" com Voltar, Pular e Avançar | | |
| 2 | Escolher Windows 10 e 32 bits; depois Windows 11 | No 10 aparece a arquitetura; no 11, o aviso de requisitos dispensados (sem escolha de 32 bits) | | |
| 3 | Caminho Ventoy → Baixar e abrir | O WinKit baixa do GitHub oficial e abre o Ventoy2Disk (o SmartScreen pode avisar) | | |
| 4 | Instalar o Ventoy num pendrive de testes, copiar a ISO e voltar → etapa Pendrive → Procurar | O pendrive Ventoy aparece | | |
| 5 | Caminho Rufus → Baixar e abrir, escolhendo uma ISO | O Rufus abre já com a ISO; gravar com "remover requisitos" e "conta local" marcados | | |
| 6 | Voltar ao WinKit, abrir o pendrive do Rufus e a etapa Começar | Aparecem as opções do Rufus, cada uma com "o WinKit também faz" | | |
| 7 | Avançar etapa por etapa, pulando duas, até Revisar e construir | A revisão lista as etapas puladas; construir funciona | | |
| 8 | Clicar direto numa seção da barra lateral no meio do fluxo | A barra de etapas acompanha ("Etapa n de N") | | |
