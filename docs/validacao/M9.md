# Validação do M9 — Janela do Agente

**Versão testada:**   **Data:**

Faça três instalações (ou edite `execution.mode` na receita e use "tentar de novo"):

| # | Modo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | `countdown` (30 s) | Janela abre no primeiro login com "Iniciando em 30 s…" e começa sozinha | | |
| 2 | `countdown`, clicar numa chave | A contagem pausa ("Contagem pausada") e espera "Iniciar" | | |
| 3 | `interactive` | Janela espera "Iniciar"; "Adiar para o próximo login" fecha e volta no próximo login | | |
| 4 | Item com "decidir na hora" desligado na janela | Aparece como "pulado — desmarcado na janela" no resumo | | |
| 5 | "Continuar em segundo plano" | Janela some; ícone na bandeja mostra o progresso; clicar no ícone reabre | | |
| 6 | `silent` | Nenhuma janela; só ícone na bandeja e notificação "WinKit concluído" | | |
| 7 | Tema escuro do Windows ligado | Janela no tema escuro | | |
| 8 | Reinício necessário com política `ask` | Diálogo "Reiniciar agora?" | | |
