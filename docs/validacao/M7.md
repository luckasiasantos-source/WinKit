## Preparação

Edite a receita (`V:\WinKit\Perfis\padrao\receita.json`) ou use o Studio (M10) para marcar:
- `bloatware.remove`: `Clipchamp.Clipchamp`, `Microsoft.BingNews`, `Microsoft.BingWeather`, `MSTeams`, `Microsoft.GetHelp`
- `tweaks`: `visual.dark_theme`, `visual.taskbar_left`, `visual.show_extensions`, `visual.classic_context_menu`, `privacy.advertising_id`, `privacy.start_bing_search`, `system.long_paths`
- `power`: `{"scheme": "high_performance", "hibernate": false, "fast_startup": false}`

```powershell
.\winkit\winkit.exe plano --pendrive V:
.\winkit\winkit.exe construir --pendrive V:
```
