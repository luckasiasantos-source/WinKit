# Validação do M17 — Inteligência do pendrive

**Versão testada:**   **Data:**   **VM:** uma VM de captura (Windows em uso) e uma VM limpa para instalar

Hipótese a confirmar: **H34** (formato do UserAssist no Windows 11 atual). Use só VMs: o assistente lê o uso de programas do usuário atual e nada sai do PC.

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Na VM de captura, instalar OBS, 7-Zip e Firefox; abrir o OBS umas 10 vezes e o Firefox 3 vezes | — | | |
| 2 | Studio → Sugestões → Analisar este PC (receita sem apps) | OBS e Firefox aparecem em "Programas que você usa", o OBS primeiro, com "Você abriu N vezes…" coerente (H34) | | |
| 3 | Criar `C:\Projetos` com mais de 100 MB e uma pasta de saves do Minecraft ou do Stardew Valley | Aparecem em "Pastas grandes" e "Saves de jogos", com o tamanho | | |
| 4 | "Ignorar" o 7-Zip (ou outro item) e analisar de novo | O item ignorado não volta | | |
| 5 | "Adicionar" o OBS e a pasta `C:\Projetos` | O OBS entra em Aplicativos (winget); a pasta entra em Backups; nada mais muda | | |
| 6 | Modelos → "Gamer" → prévia → aplicar | A prévia lista o que entra; a conta, o Wi-Fi e os backups não mudam | | |
| 7 | Exportar a receita e abrir o `.winkit.json` num editor | Sem nome de conta, senha, Wi-Fi, caminhos pessoais nem números de série | | |
| 8 | Aplicativos → Procurar atualizações num pendrive com um instalador antigo | Mostra "versão no pendrive → nova"; ao atualizar, a pasta antiga só some depois que a nova está no lugar | | |
| 9 | Revisar e construir com "Comparar com este PC" ligado; conferir `Perfis/padrao/Inventario/antes.json` | O arquivo existe com apps, dispositivos e recursos | | |
| 10 | Instalar na VM limpa com 2 apps a menos do que a VM de captura e um dispositivo sem driver | O resumo mostra "Comparação com o PC antigo" com os dois apps e o dispositivo | | |
| 11 | Instalar numa VM com hardware virtual diferente | A comparação avisa que o hardware é outro e não lista drivers | | |
