# Validação do M8 — Windows Update, reinício e resumo

**Versão testada:**   **Data:**

## Preparação

Receita com `updates.windows_update_after_install = true` e `execution.mode = "silent"`.
Teste duas vezes: com `execution.reboot_policy = "ask"` e com `"auto_if_idle"`.

## Passos

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Instalar a VM (com internet), modo silencioso | Nenhuma janela do WinKit; só a notificação final | | |
| 2 | `C:\ProgramData\WinKit\Logs\steps\windows_update_all.log` | Lista das atualizações instaladas | | |
| 3 | Política `ask` | Pergunta para reiniciar (no M8, sem janela: não reinicia; no M9: diálogo) | | |
| 4 | Política `auto_if_idle`, sem mexer na VM por 5 min após o login | Aviso de 60 s e reinício automático | | |
| 5 | Depois do reinício | A Fase 2 continua sozinha e termina | | |
| 6 | Atalho "Resumo do WinKit" | Tempo total, contagem, lista de tudo que foi feito | | |
| 7 | Forçar uma falha (ex.: app com `--args` errado) | Resumo lista a falha com a dica; atalho "Tentar de novo os que falharam (WinKit)" na área de trabalho | | |
| 8 | Usar o atalho "tentar de novo" | O app com falha é tentado de novo | | |
