# Validação do M13 — Pendrive comum (Rufus e ferramenta da Microsoft)

**Versão testada:**   **Data:**   **Versão do Rufus:**

Hipóteses a confirmar: **H16**, **H17**, **H18**. Guia: [`docs/RUFUS.md`](../RUFUS.md).

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Gravar a ISO do Windows 11 com o Rufus (GPT, UEFI, NTFS, opções da Experiência do Windows **desmarcadas**) | — | | |
| 2 | Studio → Pendrive | O pendrive aparece com o selo "Instalação (Rufus/Microsoft)"; o disco interno nunca aparece | | |
| 3 | Criar a receita e "Construir pendrive" | Na raiz do pendrive só aparece `autounattend.xml` (e a pasta `WinKit\`); nada muda em `sources\`, `boot\`, `efi\` | | |
| 4 | "Validar pendrive" | Tudo certo | | |
| 5 | Instalar na VM (USB passado para a VM) | Instala sozinho (você só escolhe o disco); Fase 1 e Fase 2 completas, conta local do WinKit | | |
| 6 | Repetir com as opções do Rufus **marcadas** | O Studio avisa; aparecem `autounattend.xml.winkit-bak` e, se o Rufus gravou, `sources\$OEM$\$$\Panther\unattend.xml.winkit-bak`; a conta local do WinKit prevalece | | |
| 7 | Pendrive da Ferramenta de Criação de Mídia (`install.esd`) | Mesmo resultado | | |
| 8 | Rufus em FAT32 com imagem dividida (`install.swm`) | A construção lê a imagem (H16) ou avisa e segue com pt-BR | | |
| 9 | Instalar com outro pendrive conectado | Anotar se o instalador usou o `autounattend.xml` certo (H18) | | |
