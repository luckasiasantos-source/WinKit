# Validação do M22 — Backup para HD secundário

**Versão testada:**   **Data:**   **PC/VM:** com um segundo disco (HD ou SSD) e um pendrive

Hipótese a confirmar: **H44** (tipo do disco pelo CIM).

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Etapa Backup do PC | Os discos aparecem com tipo (SSD, HD, NVMe, USB), sistema de arquivos e espaço livre; o disco do Windows avisa "mesmo disco" | | |
| 2 | Escolher o segundo disco → Pastas do usuário → Calcular tempo | Tamanho, número de arquivos e tempo medido no disco; avisos de espaço/nomes se houver | | |
| 3 | Fazer backup; Pausar no meio; Fazer backup de novo | Continua de onde parou; no fim "Todos conferidos" e um aviso de concluído | | |
| 4 | Abrir o Outlook (ou deixar um arquivo aberto) e refazer | O arquivo aberto é copiado pela cópia de sombra | | |
| 5 | Apagar um arquivo no PC e refazer | O arquivo continua no backup (nada é apagado) | | |
| 6 | Ligar "Compactar em .zip" num disco vazio e fazer | Um `backup.zip` que abre no Explorador | | |
| 7 | Etapa Antes de formatar | Backup conferido ✓; BitLocker (se ligado) com "Exportar chave"; ativação; "Pode formatar" só quando tudo ok | | |
| 8 | Exportar a chave do BitLocker para o pendrive | Arquivo `WinKit-chave-bitlocker.txt` com a chave de 48 dígitos | | |
| 9 | Marcar "Trazer de volta depois de instalar", construir e instalar na VM com o disco de backup ligado | Depois do login, os arquivos aparecem nas pastas do usuário novo; nada que já existia foi trocado | | |
| 10 | Num PC qualquer: Backup do PC → Trazer de volta → Restaurar aqui | Os arquivos voltam somando ao que existe | | |
