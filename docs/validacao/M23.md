# Validação do M23 — ISO personalizada e autossuficiente

**Versão testada:**   **Data:**   **PC:** Windows 11 Pro com Hyper-V; 40 GB livres

Hipóteses a confirmar: **H36** (a ISO gerada dá boot em BIOS e UEFI e instala com `install.wim` acima de 4 GB) e **H49** (ISO autossuficiente funciona sem gravar de volta na mídia).

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | Etapa ISO personalizada → escolher a ISO oficial | As edições aparecem (Home, Pro…); conferir o SHA-256 da original antes (`Get-FileHash`) | | |
| 2 | Deixar só a Pro, drivers deste PC ligados, apps de fábrica ligados → Gerar a ISO | Etapas com porcentagem (copiando, separando, drivers, gravando); a janela continua usável | | |
| 3 | No fim, `Get-FileHash` da original | Igual ao do passo 1 | | |
| 4 | `scripts/vm/nova-vm.ps1 -Iso <a nova>` (geração 2, UEFI + Secure Boot) e iniciar | Dá boot e instala só a Pro; os apps de fábrica removidos não aparecem | | |
| 5 | Mesma ISO numa VM geração 1 (BIOS) | Dá boot e o instalador abre | | |
| 6 | Construir o pendrive com uma receita, ligar "ISO autossuficiente" e gerar | A ISO contém `autounattend.xml` e a pasta `WinKit` | | |
| 7 | Instalar essa ISO numa VM sem pendrive nenhum | A instalação segue a receita (conta, apps, ajustes) sozinha; logs em `C:\ProgramData\WinKit\Logs` | | |
| 8 | Interromper no meio (fechar o WinKit) e abrir de novo | Nenhuma imagem fica montada (`Get-WindowsImage -Mounted` vazio depois de abrir a etapa e gerar de novo) | | |
