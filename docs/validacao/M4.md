# Validação do M4 — Drivers

**Versão testada:**   **Data:**

Na VM, a maioria dos dispositivos é virtual (Hyper-V), então os drivers do seu PC serão
**adicionados ao repositório de drivers** do Windows, mas não "instalados em um dispositivo"
(resultado esperado: "nenhum dispositivo presente usa este driver"). Isso já valida todo o
caminho: exportação, cópia, verificação de integridade e `pnputil`. No PC real, os drivers
são instalados nos dispositivos.

## Preparação (no seu PC, como administrador)

```powershell
.\winkit\winkit.exe coletar drivers --pendrive V: --listar
.\winkit\winkit.exe coletar drivers --pendrive V:
.\winkit\winkit.exe construir --pendrive V:
.\winkit\winkit.exe validar --pendrive V:
```

## Passos

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | `coletar drivers --listar` | Rede, chipset, vídeo e áudio marcados `[x]`; impressora `[ ]` | | |
| 2 | Pasta `V:\WinKit\Drivers\` | Uma subpasta por classe com `.inf` | | |
| 3 | `construir` | Linha "Manifesto: N arquivos" | | |
| 4 | Instalar a VM | Sem erros | | |
| 5 | `C:\ProgramData\WinKit\resumo.html` | Etapas "Driver: ..." como feitas | | |
| 6 | `pnputil /enum-drivers` na VM | Aparecem os `.inf` originais do seu PC (ex.: `rt25cx21x64.inf`) | | |
| 7 | Adulterar um arquivo em `V:\WinKit\Drivers\...` e reinstalar | Etapa daquele driver "falhou" com "corrompido ou alterado"; as outras seguem | | |
