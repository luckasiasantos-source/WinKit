**Versão testada:**   **Data:**

## Preparação (no seu PC, como administrador)

```powershell
.\winkit\winkit.exe coletar apps --pendrive V:
.\winkit\winkit.exe apps marcar 7zip notepadplusplus vlc discord --pendrive V:
.\winkit\winkit.exe apps baixar --pendrive V:          # 7-Zip, Notepad++, VLC viram offline
.\winkit\winkit.exe apps listar --pendrive V:
.\winkit\winkit.exe plano --pendrive V:
.\winkit\winkit.exe construir --pendrive V:
```

Opcional: um instalador seu — `.\winkit\winkit.exe apps adicionar --pendrive V: --instalador C:\caminho\setup.exe --nome "Meu App"`.

## Passos

| # | Passo | Esperado | Obtido | OK? |
|---|---|---|---|---|
| 1 | `coletar apps` | Lista os apps do seu PC; Discord/7-Zip com ID do winget; redistribuíveis (Visual C++) fora | | |
| 2 | `apps baixar` | "ok" para 7zip, notepadplusplus, vlc; pastas em `V:\WinKit\Apps\` | | |
| 3 | `plano` | 7-Zip/Notepad++/VLC na **Fase 1**; Discord na **Fase 2** (por usuário, winget) | | |
| 4 | Instalar a VM (com internet) | Antes da área de trabalho: 7-Zip, Notepad++, VLC já instalados | | |
| 5 | Depois do login | Discord instala sozinho e **não abre** a janela dele no final | | |
| 6 | Resumo | Todos "feitos"; nenhuma janela de instalador apareceu | | |
| 7 | VM **sem** rede (Hyper-V: desconectar o adaptador) | Discord fica "pendente — sem internet"; ao reconectar e relogar, instala | | |
